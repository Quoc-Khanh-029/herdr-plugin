# Worker report

Use these headings in order and keep the report factual:

```markdown
# Report <task-id>

- Status: <DONE | PARTIAL | NEEDS_DECISION | FAILED>
- Model: <model id>
- Date: <YYYY-MM-DD>

## Summary
- <outcome>

## Findings
- <claim with path and evidence>

## Changes made
- <file and reason, or none>

## Verification
- Done: <command and result>
- Not verified: <what could not be checked and why>

## Done criteria
- [x] / [ ] <criterion copied from task>

## Decisions needed
<options and recommendation, or none>

## Next steps
<ordered steps, or none>

END-OF-REPORT
```
