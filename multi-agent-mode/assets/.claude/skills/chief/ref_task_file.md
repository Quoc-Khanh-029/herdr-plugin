# Task-file reference

A task file is the Worker contract. Include exact Mode, Project, Scope, Constraints, acceptance criteria, and report path. READ-ONLY permits no edit other than the required report. DOC permits only named documentation. EDIT-ALLOWED permits edits only inside Scope. BUILD and board access require the corresponding Mode and named projects/devices.

Resolve ambiguous choices with the user before dispatch. State protected and generated folders explicitly. Acceptance criteria must describe observable behavior, not implementation details or a request to merely compile.
