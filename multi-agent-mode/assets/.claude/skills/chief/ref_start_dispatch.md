# Dispatch reference

1. Choose an available Worker that matches the task model and is not already working on the same code project.
2. Write the complete task file, then dispatch its path through the coordination CLI.
3. Do not poll or send additional work while that Worker is active.
4. On a signal, read the report and verify every acceptance criterion against cited evidence.
5. If a decision belongs to the user, present the options and a recommendation; do not decide for them.
